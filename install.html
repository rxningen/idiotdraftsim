Draft Room Assistant

Chrome extension · reads your live ESPN draft

What it does

Overlays a panel on your ESPN draft room showing the best players still available, ranked by your own half-PPR list. Reads your roster straight off the page so you can push it into the simulator in one paste.

Install — about two minutes

  1. Unzip it somewhere permanent

    Chrome loads the extension from this folder every time it starts. If you delete or move it, the extension stops working. Documents or your home folder is fine — not Downloads if you clear that out.

  2. Open chrome://extensions

    Paste that into the address bar. On Edge it's edge://extensions.

  3. Turn on Developer mode

    Toggle in the top-right corner of that page.

  4. Click "Load unpacked" and pick the folder

    Select the espn-ext folder you unzipped — the one containing manifest.json.

  5. Open your ESPN draft room and reload it

    The panel appears in the top-right. Extensions only attach on page load, so reload any draft tab you already had open.

  6. Click "Set available list" once

    Then click ESPN's list of available players. This teaches it where to read, and it's remembered from then on. Without it, the panel can't reliably tell who's been drafted.

Updating later

Download the new zip, replace the folder's contents, then hit the reload icon on the extension's card at chrome://extensions. Chrome caches the old files otherwise — skipping the reload is the most common reason an update seems to do nothing.

Why isn't this one click?

Chrome removed the ability for websites to install extensions directly back in 2018, and it blocks packaged .crx files downloaded from anywhere except its own store. Loading an unpacked folder is the supported route for extensions distributed outside the Web Store.

Want one-click? Publishing to the Chrome Web Store gets you a real "Add to Chrome" button. It costs a one-time $5 developer registration and the listing goes through a review that usually takes a few days.

If something looks wrong

SymptomWhat to do
No panel at allReload the draft page. Confirm the URL starts with fantasy.espn.com.
"Can't tell who's available"Click Set available list, then click ESPN's player list.
Lists players already draftedThe available list is pointing at the wrong element — run Set available list again.
Names show "not in rankings"Add them in the simulator's Player pool tab, or use Copy ESPN pool → rankings.
An update changed nothingHit the reload icon on the extension card.

Still stuck? Click Copy diagnostics in the panel — it reports what the extension can actually see on the page, with your league IDs redacted.
